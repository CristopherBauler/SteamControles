0. Como usar este PDF

Este arquivo é o mapa do app para quem programa. A fonte é HTML (fácil de editar). Sempre que a arquitetura mudar (nova camada, novo sync, nova persistência), atualize o HTML e rode npm run docs:pdf. Não descreva cada diff de CSS; descreva o porquê e o fluxo.

1. O que o produto é

Dashboard local da wishlist Steam, em BRL, com cinco superfícies: Novidades, Wishlist, Loja, Jogos, Não vou jogar (backlog). Nome de exibição: Minha Loja dos Desejos. Código ainda usa pastas SteamControles / dev.steamcontroles.app.

Não é um servidor na nuvem. Cada instalação puxa APIs públicas (Steam, gg.deals) e grava JSON no disco. GitHub guarda só código. SteamID, marcações e cache ficam fora do git.

2. Passo a passo de como nasceu

  1. Caderno no Obsidian. Scripts Node 18+ em Scripts/ baixavam a wishlist pública, gravavam Data/*.json e montavam Markdown + HTML estático. Sem npm de runtime, sem TypeScript. O Obsidian corta JS das notas, então o painel lá é HTML morto + CSS de snippet.
  2. Motor único. Scripts/updateWishlist.js virou o orquestrador: wishlist → preços → loja → notícias → backlog. steamApi.js fala com a Valve. ggDeals.js raspa o site (Cloudflare). backlog.js junta biblioteca + “Não vou jogar”.
  3. Casca Windows: Electron. Chromium + Node no mesmo processo. desktop/main.js (main process) tem janela, bandeja, IPC, timers. desktop/preload.js expõe window.steamApp sem dar Node ao renderer. desktop/renderer/ é a UI (HTML/CSS/JS). Programas: Node, npm, Electron 35, electron-builder (gera o exe portable).
  4. Login. OpenID oficial da Steam (Scripts/steamLogin.js). Senha nunca passa pelo app. Wishlist precisa estar pública. Biblioteca completa pede Detalhes dos jogos públicos e/ou chave Web API.
  5. Celular (depois do PC). Capacitor 7 empacota o mesmo renderer num WebView Android. steamApp.mobile.js imita o preload. Sem o cliente Steam no telefone, Jogos/backlog completos vêm do PC na LAN (desktop/phoneLink.js, porta 17331).

Sim: a maior parte é buscada de sites. Não. Nada disso é “nossa nuvem”. É a nuvem da Valve / do gg.deals.

5. Persistência (o ponto das 700 marcações)

Wishlist/notícias/loja voltam da internet depois de reinstalar, desde que o cara conecte a Steam de novo. “Não vou jogar”, cores, intervalo de sync e SteamID não existem na Valve. São dados do app.

  1. Fonte da verdade das marcações: Data/backlogDone.json (appIds + snapshot do jogo).
  2. Espelho automático em %AppData%\Roaming\MinhaLojaDosDesejos\. Desinstalar o atalho não apaga isso.
  3. Ajustes → Exportar cópia / Restaurar cópia: JSON único para formatar o Windows ou trocar de PC.
  4. O usuário não precisa abrir pasta nem editar JSON. Caminhos crus saíram da UI de propósito.

Rodando da pasta do vault no OneDrive, o Data/ já é sincronizado pelo OneDrive. Apagar a pasta do projeto ainda mata o cache da wishlist — a cópia AppData + o botão Exportar cobrem as marcações.

6. Timers de sync (PC)

  • Loja (Steam hub + gg.deals): sozinha a cada 30 minutos. Não espera o intervalo da wishlist.
  • Wishlist + Novidades + Jogos/backlog: o que o usuário escolhe em Ajustes (6 / 12 / 24 h). No PC isso é o timer da bandeja. No celular vale ao reabrir o app ou tocar Atualizar. Os dois intervalos são independentes.
  • Atualizar agora: sync completo (se estiver logado). Inclui Loja.
  • Bug antigo: o scrape do gg.deals era cacheado para sempre no processo Electron. Um “atualizar” não relia o site. Isso foi removido.

7. Disponibilizar para outra pessoa sem ela subir backend

Sim. Cada um instala o .exe ou o APK, conecta a Steam, o app puxa as APIs. Quem recebe não precisa de servidor. Wishlist pública cobre Novidades e Wishlist; Loja nem login precisa. Marcações ficam no aparelho dela (AppData + Exportar cópia).

Celular: a primeira ligação Wi‑Fi espelha o PC. Depois wishlist/loja/notícias atualizam na Steam daquele telefone (intervalo próprio nos Ajustes; vale ao reabrir o app). Só a lista Não vou jogar continua cruzando com o PC quando os dois estão na mesma LAN. Fora de casa as marcas novas esperam voltar no Wi‑Fi (ou, no futuro, uma nuvem que nós hospedamos).
